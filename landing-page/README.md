# Ollinati Catering - Landing Page

A modern, responsive landing page for Ollinati Catering services.

## Features

- Modern, responsive design
- Beautiful gradient hero section
- Navigation with logo
- Mobile-friendly layout

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```

## Technologies Used

- React 19
- Vite
- React Router DOM
- CSS3 with modern features
